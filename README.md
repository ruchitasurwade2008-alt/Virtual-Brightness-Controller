# Virtual Brightness Controller 💡

A Python-based Virtual Brightness Controller that allows users to control their computer screen brightness using hand gestures.

## Technologies Used

* Python
* OpenCV
* MediaPipe
* Screen Brightness Control

## Features

* Hand gesture detection
* Real-time hand tracking
* Brightness control using finger distance
* Control screen brightness without using keyboard buttons

## Requirements

Install the required libraries:

```bash
pip install opencv-python mediapipe screen-brightness-control
```

## How to Run

1. Install Python.
2. Install the required libraries.
3. Connect your webcam.
4. Run the Python file:

```bash
python VIRTUAL_BRIGHTNESS.PY
```

## Project

This project uses computer vision and hand tracking to control the computer screen brightness through hand gestures.
